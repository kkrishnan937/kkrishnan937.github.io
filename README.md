# Business analysis portfolio website

[Live portfolio](https://kkrishnan937.github.io/)

Static portfolio source for ShopStack cart review and Municipal Enquiry AI Assessment. The project repositories remain the evidence sources.

- `index.html`: introduction, selected projects and approach.
- `shopstack.html`: cart-review case study.
- `municipal.html`: enquiry-assessment case study.
- `assets/`: shared styling, mobile navigation and retained project images.

Preview from this directory with `node preview-server.cjs`, then open `http://127.0.0.1:8771/`. No application model, dataset or acceptance test is run by this site. The buildless files can be served from the root of a GitHub Pages repository.

Images are copies of existing project evidence, not new test executions. Scope, contribution and evidence limitations are stated on the project pages.
